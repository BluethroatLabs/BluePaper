For general questions and reproducible bugs, open an issue in the BluePaper repository. Public issues are visible to everyone.

What to include

  • The browser or API client and operating system you used.
  • The file type, approximate size, and whether OCR was selected.
  • What you expected, what happened, and steps to reproduce it.
  • A synthetic sample document, only if a file is needed to reproduce the issue.

Do not post private documents, conversion IDs, API keys, or other secrets in a public issue.

Security reports

Do not report a suspected security or privacy vulnerability in a public issue. Use a private reporting channel offered by the repository maintainers.

Using the service

Choose a supported file, complete the browser challenge, and queue conversion. When it finishes, inspect the report and download the rebuilt PDF. The API documentation describes integration endpoints. The About dialog explains the workflow and its limits.
