These terms describe the BluePaper web console and conversion API. BluePaper accepts an untrusted document, rebuilds a PDF from pixels, and may produce a raw byte-indicator report. You decide whether to upload a file and whether to use or share the output.

What conversion does

Pixel reconstruction is intended to remove active document constructs, but it can change layout, remove interactive features, and lose some content. Optional OCR can introduce recognition errors. Review the rebuilt PDF before relying on it.

A report hit does not prove that an active construct was present. Zero hits is not a finding that a file is clean. BluePaper does not certify a document as safe or free of malware.

Your documents

Upload only files you are permitted to process. The service stores uploaded originals and generated artifacts as described in the Privacy notice. A browser conversion ID grants access to that conversion’s output; keep it private.
