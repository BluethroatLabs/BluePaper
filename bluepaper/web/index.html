About BluePaper

Open the original only inside a disposable conversion sandbox. Bring back pixels, then build a new PDF.

What happens to a document?

BluePaper hashes and stores the upload, scans its raw bytes for selected indicators, and sends it to an isolated sandbox for conversion. The trusted worker builds a new PDF from the returned pixels. Optional OCR adds searchable text.

What does the report mean?

A hit identifies a byte pattern in the original. A hit does not mean that construct was present. Absence of patterns is not a malware verdict. Conversion runs either way.

Can I sign the output?

Yes. Place a visual signature on the rebuilt PDF and download a signed copy. This is not a cryptographic signature; the stored PDF stays unchanged.

Where does my file go?

This is a hosted service: your document is uploaded for processing. Read the privacy notice for storage and deletion details before sending sensitive material.
