The original file is opened only inside an isolated sandbox. Pixel reconstruction cannot carry JavaScript, macros, embedded executables, or most metadata.

The regexp pass lists raw byte indicators such as /JavaScript, /Launch, or vbaProject.bin. A hit does not mean that construct was present.

Absence of patterns is not a malware verdict. Conversion still runs.
